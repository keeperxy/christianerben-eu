## Direction Suggestions

1. Treat the AI-facing surface as a maintained product surface. `next.config.mjs` advertises `/llms.txt` and rewrites `Accept: text/markdown` requests, while certificate evidence exists in `src/components/CertificatesSection.tsx` and `public/certificate`. A follow-up could add certificate metadata to `llms.txt` and the markdown homepage output so recruiter/agent workflows can discover proof artifacts without rendering the page.
2. Decide whether the hidden CV editor is supported internal tooling or legacy. If supported, make `/cv` custom data validation and share semantics explicit; if not, remove the hidden seven-click editor path and keep the public CV page static-first.
3. Promote the dependency release workflow from local agent lore to a portable runbook contract. The repo already has CI and a rich local skill; one maintained reference plus static tests for command/path drift would reduce future release risk.
